# Tela de Login Animada

Projeto desenvolvido como material de estudo e prática para a disciplina de Programação IV. O objetivo principal é a criação de uma interface de autenticação (Login e Cadastro) moderna, interativa e fluida, utilizando tecnologias web fundamentais (HTML, CSS e JavaScript puros).

## Tecnologias Utilizadas

- **HTML5:** Estruturação semântica dos formulários de autenticação.
- **CSS3:** Estilização moderna, layout responsivo e transições/animações fluidas (`@keyframes`) para alternância entre os painéis.
- **JavaScript (Vanilla):** Manipulação do DOM para gerenciar a troca dinâmica de estados entre as telas de login e registro.

## Funcionalidades

- **Painel Duplo Dinâmico:** Alternância suave entre os formulários de *Sign In* (Entrar) e *Sign Up* (Cadastrar) no mesmo espaço de tela.
- **Animações de Transição:** Efeito visual moderno de deslocamento lateral e sobreposição ao mudar o foco do usuário.
- **Interface Limpa:** Design focado na experiência do usuário (UX), ideal para ser integrado como módulo de autenticação em sistemas web maiores.
